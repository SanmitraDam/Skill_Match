1. EXECUTIVE SUMMARY & WHAT THIS PROJECT IS (IN SIMPLE WORDS)
====================================================================================================

SkillMatch DNA is an all-in-one, intelligent career preparation and hiring verification platform. 

In simple terms:
Think of SkillMatch as a combination of an ultra-smart resume scanner, a private AI interview coach, 
an adaptive technical testing system, an ambient exam proctor, a personalized tutor, and a 
verified professional social network like LinkedIn—all rolled into one unified application.

Instead of just checking if certain keywords appear on a piece of paper, SkillMatch measures a 
candidate's real-world "Technical DNA":
1. It reads your resume and extracts your genuine technical competencies.
2. It removes your personal details (name, email, phone) to make sure there is zero hiring bias.
3. It compares your skills against the job you want using 384-dimensional mathematical vectors.
4. It tells you exactly what skills you are missing, how much money those missing skills cost you in salary, 
   and how much they reduce your chances of getting an interview callback.
5. It conducts an Adaptive Multiple-Choice Quiz that automatically adjusts its difficulty based on your answers:
   if you get questions right, it gets harder; if you get them wrong, it gets easier.
6. It runs a Realistic AI Voice Interview where the AI asks spoken questions out loud, listens to your 
   spoken answers through your microphone, cancels out background noise, and grades your technical depth 
   and communication clarity.
7. It combines everything into a single, verified master score called the Composite Career Readiness Score (CCRS).
8. If you have any gaps, it automatically writes a personalized 4-Week Learning Roadmap with links to free 
   tutorials and study guides to help you master what you missed.
9. It provides verified badges and posts on a LinkedIn-style social feed so recruiters can see proven proof 
   of your skills rather than just buzzwords.

2. WHY SKILLMATCH WAS BUILT (THE REAL-WORLD PROBLEM IT SOLVES)
====================================================================================================

Traditional recruitment systems are fundamentally broken for both candidates and employers:

* PROBLEM 1: THE ATS "BLACK HOLE"
  Traditional Applicant Tracking Systems (ATS) use crude keyword filters. Over 75% of qualified resumes 
  are rejected automatically without a human ever seeing them, and the candidate gets a generic rejection 
  email with zero constructive feedback.

* PROBLEM 2: RESUME CHEATING & KEYWORD STUFFING
  Candidates copy-paste buzzwords from the job description in tiny white fonts to game the keyword search. 
  This fills candidate pipelines with unqualified applicants and wastes engineering managers' time.

* PROBLEM 3: UNCONSCIOUS BIAS
  Traditional hiring often suffers from conscious and unconscious bias based on a candidate's name, gender, 
  address, or educational pedigree rather than their actual technical capabilities.

* PROBLEM 4: NO ACTIONABLE ROADMAP FOR JOB SEEKERS
  Job seekers never know why they were rejected. They do not know which specific skill they lacked, 
  how to test themselves, or what to study next to become qualified.

* HOW SKILLMATCH SOLVES THIS:
  SkillMatch turns hiring into an open, honest, and verifiable closed loop. It tests what you actually know, 
  protects your privacy with PII masking, coaches you on your verbal communication, grades you with scientific 
  fairness, and gives you the exact blueprint to improve.

5. DETAILED FEATURE-BY-FEATURE EXPLANATION ("FEATURE ALL")
====================================================================================================

Below is an exhaustive, easy-to-understand breakdown of every feature built into SkillMatch DNA:

----------------------------------------------------------------------------------------------------
FEATURE 1: PRODUCTION INPUT DNA MATRIX ENGINE (RESUME & JD INGESTION)
----------------------------------------------------------------------------------------------------
* What it is:
  The entry point for candidates. It accepts resumes in any common format (PDF, DOCX, TXT) and target 
  job descriptions, converting unstructured text into a clean, verified list of technical skills.
* How it works:
  1. High-Speed PDF Parsing: PyMuPDF streams the document and extracts text in under 150 milliseconds.
  2. OCR Fallback: If a candidate uploads a scanned image PDF, Tesseract OCR extracts the text automatically.
  3. Bias-Free Presidio PII Masking: The engine scrubs personal identifiers (first/last names, phone 
     numbers, emails, physical addresses). This ensures that downstream vector matching and grading are 
     100% merit-based, complying with New York City Local Law 144 and the EU AI Act.
  4. Lightcast Open Skills Taxonomy: Raw phrases like "postgres", "pg", or "PostgreSQL DB" are all 
     standardized to the canonical term "PostgreSQL". It understands 34,000+ technical skills.
  5. Social Link Discovery: Automatically identifies and validates candidate GitHub, LinkedIn, and 
     portfolio URLs from the resume header.

----------------------------------------------------------------------------------------------------
FEATURE 2: HYBRID DENSE VECTOR & LEXICAL SKILL MATCHING
----------------------------------------------------------------------------------------------------
* What it is:
  The matching engine that compares what the candidate knows against what the job requires.
* How it works:
  1. Dense Semantic Projections: Instead of just searching for matching letters, the engine uses the 
     `all-MiniLM-L6-v2` transformer model to convert skills into 384-dimensional vectors. It understands 
     that "Docker" and "Containerization" are conceptually related even if the words differ.
  2. Cosine Similarity: Computes the mathematical angle between the candidate's skill vector and the job 
     vector, producing an accurate Match Score between 0.0% and 100.0%.
  3. Jaccard Set Overlap Fallback: If running on a very low-power device where neural networks are disabled, 
     the engine smoothly falls back to set-theoretic overlap so matching never fails.
  4. 3-Color Categorized Gap Partitioning:
     - Matched Skills (Bioluminescent Emerald #10B981): Skills present in both resume and JD.
     - Partial Matches (Cyber Amber #F59E0B): Closely related or adjacent skills.
     - Critical Missing Gaps (Crimson Red #EF4444): Vital skills required by the job that the candidate lacks.

----------------------------------------------------------------------------------------------------
FEATURE 3: REAL-TIME SKILL GAP INTELLIGENCE & ECONOMIC MODELING
----------------------------------------------------------------------------------------------------
* What it is:
  A diagnostic engine that translates abstract missing skills into real career and financial consequences.
* How it works:
  1. Gap Priority Scoring: Ranks missing skills from highest to lowest importance based on how often they 
     appear in the job description and whether they are fundamental prerequisites.
  2. Hiring Velocity Impact: Calculates the exact percentage drop in interview callback likelihood 
     caused by each specific missing skill (e.g., "Missing Kubernetes reduces interview callbacks by 32%").
  3. Salary Deficit Modeling: Estimates the market compensation dollar penalty for lacking that skill 
     (e.g., "Lacking PyTorch is associated with a $14,500 average annual salary gap in this role").
  4. Skill Bridge Recommendations: Identifies "stepping stone" skills you already know to help you learn 
     the missing skill faster (e.g., "Since you know SQL and FastAPI, learning PostgreSQL will only take 4 days").

----------------------------------------------------------------------------------------------------
FEATURE 4: COMPUTERIZED ADAPTIVE TESTING (CAT) ENGINE
----------------------------------------------------------------------------------------------------
* What it is:
  An intelligent multiple-choice testing studio that adjusts its questions in real time based on how well 
  you are doing, preventing boring questions that are too easy or frustrating questions that are too hard.
* How it works:
  1. Item Response Theory (IRT 2PL Model): Every question has a calibrated difficulty tier (from 1.0 to 5.0).
  2. Dynamic Adaptation Rule:
     - If you answer correctly, difficulty increases by +0.40.
     - If you answer incorrectly, difficulty decreases by -0.60.
  3. Targeted at Missing Skills: The quiz does not ask random trivia; it specifically tests the critical 
     skill gaps identified in Feature 3.
  4. AI Question Generation: Groq Cloud (Llama-3-70B) or local Ollama writes fresh, high-level conceptual 
     questions on the fly.
  5. Deterministic Offline Question Bank: If your internet goes down or the AI API is unavailable, the 
     engine instantly serves questions from a curated offline database of 500+ seed questions.
  6. Peak-Difficulty Calibrated Score: You are rewarded for answering harder questions. A candidate who gets 
     4 hard questions right scores higher than someone who gets 4 easy questions right.

----------------------------------------------------------------------------------------------------
FEATURE 5: SPATIAL AI VOICE MOCK INTERVIEW STUDIO & ANC STUDIO
----------------------------------------------------------------------------------------------------
* What it is:
  A realistic voice-based mock interview room where a neural AI speaks questions out loud, listens to you 
  speak your answers through your microphone, removes background noise, and grades your response.
* How it works:
  1. Neural Text-to-Speech (Edge-TTS): The AI generates human-sounding speech using Microsoft's 
     neural voice (`en-US-ChristopherNeural`) and streams MP3 audio to your browser.
  2. 3D AudioSphere Visualizer: An interactive Three.js sphere pulses and deforms its surface in real time 
     matching the frequency of the AI's voice and your voice.
  3. Web Audio Recording: Captures your spoken response in standard WAV format directly from your browser.
  4. Ultra-Fast Speech-to-Text (Faster-Whisper): Transcribes 15 seconds of spoken audio on CPU in under 
     500 milliseconds.
  5. Multi-Criteria Rubric Grading:
     - Technical Accuracy (70% weight): Verifies architectural correctness, complexity analysis, and edge cases.
     - Communication Clarity (30% weight): Evaluates conciseness, structure, articulation, and filler words.
  6. Active Noise Cancellation (ANC) DSP Filter:
     - Filters out keyboard clicks, fan hums, and background room clatter using WebAudio biquad filters.
     - Shows a live status badge: `[ ANC Active • Background Noise Dampened ]`.
  7. Post-Interview Dual-Audio Comparison Player:
     - Candidates and recruiters can listen to a side-by-side comparison of "Raw Microphone Audio" vs. 
       "Filtered ANC Audio" to verify that audio processing worked perfectly.
  8. Smart Surrender & Auto-Advancement:
     - If a candidate says "I don't know", "idk", "pass", or "skip", the system detects the surrender intent 
       instantly and advances to the next question with zero awkward silence.

FEATURE 6: COMPOSITE CAREER READINESS SCORE (CCRS) & 4-WEEK DYNAMIC ROADMAP
----------------------------------------------------------------------------------------------------
* What it is:
  The master calculation that determines how ready a candidate is for a job, followed by an actionable 
  recovery curriculum.
* How it works:
  1. CCRS Mathematical Formula:
     CCRS = (30% x Vector Match Score) + (35% x Adaptive Quiz Score) + (35% x Voice Interview Score)
  2. Readiness Tiers:
     - 0% - 49%: Foundation Deficit (Needs structured beginner training).
     - 50% - 69%: Developing Competency (Good basics, lacks specialized depth).
     - 70% - 79%: Proficient (Solid technical grasp, minor gaps).
     - 80% - 100%: Interview Ready / Elite (Cleared for immediate enterprise interviews).
  3. 4-Week Hyper-Personalized Learning Roadmap:
     - Week 1: Core Fundamentals & Syntax of missing tools.
     - Week 2: Architectural Patterns & Best Practices.
     - Week 3: Real-World Hands-on Project Implementation.
     - Week 4: Performance Optimization & Verbal Defense Practice.
  4. Vetted Free Learning Resources: Automatically attaches direct links to official documentation, 
     free interactive tutorials, and open-source GitHub repositories for each week's topic.

* What it is:
  A non-invasive cheating-prevention suite that monitors test integrity during quizzes and voice interviews.
* How it works:

     - Monitors webcam video for face presence, secondary faces in the room, and continuous off-screen gaze diversion.
  2. Audio Proctoring (`/audio-proctor`):
     - Detects sudden decibel spikes, background whispers, or secondary speaker voices.
  3. Browser Guard (`/browser-guard`):
     - Tracks tab switching, browser window blur, exiting fullscreen mode, and clipboard paste actions.
  4. Proctoring Trust Score (PTS) (`/proctoring-pts`):
     - Starts at 100. Minor infractions deduct points. A score below 75 triggers a review flag.
  5. Zero-Knowledge Verifiable Proofs (ZK-STARKs):

----------------------------------------------------------------------------------------------------

  2. Automated Q&A Generation: Generates question-and-answer flashcard decks for each chapter.
  3. Ebbinghaus Forgetting Curve Modeling:
     - Tracks memory decay using the formula: R = e^(-t/S) (where R is retention, t is time, S is stability).
  4. SuperMemo-2 (SM-2) Spaced Repetition:

FEATURE 10: JD-TAILORED CV BUILDER & INTEGRATED ATS COMPATIBILITY CHECKER
----------------------------------------------------------------------------------------------------
* What it is:
  A smart resume generator that tailors your resume to a specific job description and rates how well it

6. STEP-BY-STEP USER JOURNEY: HOW EVERYTHING WORKS TOGETHER
====================================================================================================

Here is how a real user experiences the platform from start to finish:

STEP 1: INGESTION & BIAS-FREE MASKING
  * Candidate visits the portal and uploads their resume (PDF or DOCX).
  * Candidate pastes the job description they are targeting.
  * Candidate toggles "Bias-Free PII Masking".
  * The system strips their name, phone, and email, parses their skills via PyMuPDF, and standardizes 
    everything against the Lightcast 34k taxonomy.

STEP 2: VECTOR MATCHING & GAP INTELLIGENCE
  * The system computes 384-dimensional dense vectors and runs Cosine Similarity.
  * The candidate sees their Match Score (e.g. 68.5%) and a 3-way color-coded breakdown:
    - Matched Skills (Green)
    - Partial Matches (Amber)
    - Critical Missing Skills (Red)
  * The Gap Intelligence Engine alerts the candidate:
    "Missing PyTorch and Kubernetes reduces your interview callbacks by 34% and costs ~$18,000 in salary."

STEP 3: ADAPTIVE CAT TESTING (TESTING THE GAPS)
  * The candidate clicks "Start Adaptive Quiz".
  * The system does not ask generic questions; it creates questions specifically targeting PyTorch and Kubernetes.
  * The first question starts at medium difficulty (Tier 3.0).
  * If the candidate answers correctly, the next question jumps to Tier 3.4.
  * If incorrect, it drops to Tier 2.8.
  * After 5 questions, the candidate earns a peak-calibrated Quiz Score (e.g., 85.0%).

STEP 4: AI VOICE MOCK INTERVIEW
  * The candidate enters the Voice Interview Studio.
  * The AI voice speaks an architectural question:
    "Explain how you would deploy a containerized PyTorch inference service on Kubernetes with auto-scaling."
  * The candidate speaks their answer into their microphone.
  * Active Noise Cancellation filters room noise.
  * Faster-Whisper transcribes the answer in 400ms.
  * The AI grades the answer: Technical Accuracy (82/100), Communication Clarity (86/100).

STEP 5: COMPOSITE READINESS SCORE (CCRS) & 4-WEEK ROADMAP
  * The system computes the CCRS:
    CCRS = (0.30 x 68.5) + (0.35 x 85.0) + (0.35 x 84.0) = 79.7% (Proficient Tier).
  * The system immediately synthesizes a 4-Week Step-by-Step Learning Roadmap with links to free 
    tutorials to help the candidate master Kubernetes and reach 90%+.

STEP 6: SOCIAL SHARING & RECRUITER DISCOVERY
  * The candidate's verified milestone is published to the LinkedIn-style Readiness Feed.
  * Recruiters browsing the platform filter by candidates with CCRS >= 75% and inspect the candidate's 
    radar chart and 15-second voice introduction.
  * The recruiter initiates an interview through the ATS Gateway.

7. DATABASE SCHEMA & DATA MODELS (EXPLAINED IN EASY TERMS)
====================================================================================================

The database is managed with SQLAlchemy ORM (`backend/app/models/models.py`) and supports SQLite and PostgreSQL.
Here is what each primary table stores:

1. `users`:
   Stores user accounts, encrypted passwords (Argon2id), roles (candidate, recruiter, admin), and tenant ID.
2. `resumes`:
   Stores uploaded resume files, extracted raw text, and parsed standardized skill lists.
3. `job_descriptions`:
   Stores employer job requirements, role titles, and required skill lists.
4. `skill_match_results`:
   Stores the match score percentage, matched skills, missing skills, and timestamps linking resumes to JDs.
5. `quiz_results`:
   Stores the final CAT quiz score, peak difficulty reached (1.0 to 5.0), and individual question logs.
6. `interview_results`:
   Stores the voice interview score, speech transcript, technical accuracy, clarity score, and AI feedback.
7. `readiness_scores`:
   Stores the final Composite Career Readiness Score (CCRS) combining match, quiz, and voice results.
8. `roadmaps`:
   Stores the personalized 4-week recovery curriculum in JSON format with weekly tasks and resources.
9. `candidate_skill_vectors`:
   Stores the 384-dimensional numerical vector embeddings for each skill.
10. `compliance_attestations`:
    Stores cryptographic Ed25519 digital signatures, Four-Fifths compliance ratios, and SHA-256 audit hashes.
11. `audit_logs`:
    Tamper-evident system activity log recording who performed what action and when.
12. `readiness_posts`:
    Stores social feed posts, verification badges, likes, and skill duel milestones.
13. `profile_views`:
    Stores logs of which recruiters viewed which candidate profiles to compute reach analytics.
14. `talent_liquidity_pools` & `swarm_market_bids`:
    Stores AMM skill token balances, bonding curve parameters, and decentralized bids.

8. REST API CATALOG & CORE ENDPOINT REFERENCE
====================================================================================================

The FastAPI backend exposes 194 endpoints across 91 router modules. Here are the core endpoints:

1. AUTHENTICATION & USERS (`/auth`)
   * `POST /auth/register` - Create new candidate or recruiter account.
   * `POST /auth/token` - Authenticate with username/password and receive JWT access token.
   * `GET  /auth/me` - Retrieve current user profile and role.

2. RESUME INGESTION & SKILL MATCHING (`/dna`, `/skills`)
   * `POST /dna/parse-resume` - Upload PDF/DOCX resume, apply PII masking, return standardized skills.
   * `POST /dna/match` - Run 384-d cosine similarity between candidate skills and job requirements.
   * `POST /dna/full-pipeline` - End-to-end endpoint: upload resume + JD text, receive full gap report.
   * `POST /skills/parse-jd` - Normalize unstructured job description text.

3. SKILL GAP INTELLIGENCE (`/gap-intelligence`)
   * `POST /gap-intelligence/analyze` - Calculate gap priority, hiring velocity impact, and salary deficit.

4. ADAPTIVE CAT QUIZ (`/quiz`)
   * `POST /quiz/start/{match_id}` - Start new adaptive quiz session targeting missing skills.
   * `POST /quiz/next-question/{session_id}` - Fetch next question calibrated to candidate's current ability.
   * `POST /quiz/submit-answer/{session_id}` - Submit answer, update difficulty via IRT, receive result.
   * `POST /quiz/finish/{session_id}` - Finalize quiz and record peak difficulty score.

5. AI VOICE MOCK INTERVIEW (`/interview`)
   * `POST /interview/start/{match_id}` - Initialize voice interview session.
   * `POST /interview/next-question/{interview_id}` - Generate new question and synthesize Edge-TTS audio.
   * `POST /interview/submit-answer/{interview_id}` - Upload WAV audio answer; run Whisper STT & grade rubric.
   * `POST /interview/finish/{interview_id}` - Finalize interview session and compute final voice score.

6. CAREER READINESS & ROADMAP (`/readiness`)
   * `POST /readiness/calculate/{match_id}` - Compute holistic CCRS (30% Match + 35% Quiz + 35% Voice).
   * `POST /readiness/generate-roadmap/{readiness_id}` - Generate personalized 4-week learning plan.

7. AMBIENT PROCTORING (`/proctoring`, `/vision-proctor`, `/audio-proctor`, `/browser-guard`)
   * `POST /proctoring/vision/event` - Record gaze diversion or multi-face detection.
   * `POST /proctoring/audio/event` - Record decibel spike or secondary speech detection.
   * `POST /proctoring/browser/event` - Record tab switch, blur, or clipboard paste.
   * `GET  /proctoring/score/{session_id}` - Fetch real-time Proctoring Trust Score (PTS).

8. SOCIAL READINESS NETWORK (`/readiness/feed`, `/readiness/profile`)
   * `GET  /readiness/feed` - Fetch verified candidate milestone posts.
   * `POST /readiness/profile/view` - Record recruiter profile view.
   * `GET  /readiness/profile/{candidate_id}` - Fetch candidate identity hub and radar metrics.

9. LOCAL INSTALLATION & RUNBOOK (HOW TO RUN EVERYTHING LOCALLY)
====================================================================================================

You can run SkillMatch locally on your machine with zero configuration.

----------------------------------------------------------------------------------------------------
STEP 1: SYSTEM PREREQUISITES
----------------------------------------------------------------------------------------------------
* Operating System: Windows 10/11, macOS, or Linux (Ubuntu 22.04+).
* Python: Version 3.11 or 3.12 installed and added to PATH.
* Node.js: Version 18.x or 20.x (only needed if running the Next.js 3D web app).
* Git: Installed.

----------------------------------------------------------------------------------------------------
STEP 2: PYTHON VIRTUAL ENVIRONMENT & DEPENDENCIES
----------------------------------------------------------------------------------------------------
Open a terminal in the project directory:

```bash
# 1. Create and activate a virtual environment
# On Windows:
python -m venv .venv
.\.venv\Scripts\activate

# On Mac/Linux:
python3 -m venv .venv
source .venv/bin/activate

# 2. Upgrade pip and install all backend dependencies
pip install --upgrade pip
pip install -r backend/requirements.txt

# 3. Download the spaCy English NLP language model
python -m spacy download en_core_web_sm
```

----------------------------------------------------------------------------------------------------
STEP 3: CONFIGURE ENVIRONMENT VARIABLES (.env)
----------------------------------------------------------------------------------------------------
A default `.env` is already included. You can inspect or update it:
```ini
DATABASE_URL=sqlite:///./skillmatch.db
SECRET_KEY=dev-secret-key-change-in-production-random-64-char
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60
GROQ_API_KEY=your_groq_api_key_here    # Optional: Free tier at console.groq.com
STORAGE_TYPE=local
```
Note: If you do not have a Groq API key, the system automatically uses its built-in offline question 
bank, so you do not need any paid subscriptions!

----------------------------------------------------------------------------------------------------
STEP 4: INSTALL FRONTEND DEPENDENCIES (FOR NEXT.JS 3D CANVAS)
----------------------------------------------------------------------------------------------------
```bash
cd frontend/dna-web
npm install
cd ../..
```

----------------------------------------------------------------------------------------------------
STEP 5: LAUNCH THE APPLICATION
----------------------------------------------------------------------------------------------------
You have 3 easy ways to launch:

OPTION 1: THE ALL-IN-ONE SUPERVISOR (Runs FastAPI Backend + Next.js 3D Web App)
```bash
python run_local.py
```
* Next.js 3D Web App:  http://localhost:3000
* FastAPI Backend API: http://localhost:8000
* Interactive Swagger: http://localhost:8000/docs
* Health Telemetry:    http://localhost:8000/health

OPTION 3: RUN BACKEND DIRECTLY VIA UVICORN
```bash
uvicorn --app-dir backend app.main:app --host 0.0.0.0 --port 8000 --reload
```
